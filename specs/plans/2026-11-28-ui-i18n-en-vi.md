# Static UI Internationalization (`EN` / `VI`) Implementation Plan

> **Execution:** Execute this plan inline via `executing-plans` (followed by mandatory `evaluating-features` before `"done"`). For Role-DAG full-stack `feature_list.json` delivery from `specs/prd.md` + `designs/`, run `.agents/workflows/feature_delivery.py` directly instead of authoring a `specs/plans/*.md` file.

**Goal:** Add zero-dependency `EN` (default) / `VI` static UI localization across all 5 portfolio routes with persistent `localStorage['lg-lang']`, `<html lang>` sync, accessible Navbar switchers, UTC-safe dates, and localized Zod form alerts. | **Spec:** `specs/designs/2026-11-28-ui-i18n-en-vi-design.md` | **Tech Stack:** TypeScript, React 19, Vite 8, Tailwind CSS, Zustand, Zod v4 + React Hook Form, Vitest + RTL, Playwright

## Global Constraints & Review Focus
- Zero external i18n packages; 100% arrow functions in `apps/web/src/**/*.{ts,tsx}`; zero `any` / `@ts-ignore`; selector-scoped `usePortfolioStore((s) => s.locale)`; dynamic PostgreSQL fields and `specs/contracts/portfolio.ts` stay untouched.
- **Edge Case 1 (Corrupted `localStorage['lg-lang']`):** Unknown values (e.g. `'fr'`, `''`) fall back strictly to `'en'` in both `apps/web/index.html` and `usePortfolioStore.ts` (tested in Task 1).
- **Edge Case 2 (Mid-filter locale switch):** `selectedProjectCategory` and `selectedCategory` keep internal value `'All'` while rendering localized chip labels (`'Tất cả dự án'` / `'Tất cả'`) so active filters never break on toggle (tested in Task 2).
- **Edge Case 3 (Live Zod alert re-translation):** Validation errors already visible in `ContactForm` translate immediately when `locale` toggles `en <-> vi` without re-submitting (tested in Task 3).
- **Edge Case 4 (UTC calendar date formatting in `vi`):** `'2024-01-01'` formats with `timeZone: 'UTC'` in both `'en'` (`'Jan 2024 — Present'`) and `'vi'` (`'Thg 1, 2024 — Hiện tại'`) without Western-offset month shift (tested in Task 3).
- **Edge Case 5 (`768x1024` & `375x812` Vietnamese Navbar width):** `header nav` maintains `scrollWidth <= clientWidth` across all 5 routes at `1280x800`, `768x1024`, and `375x812` in `'vi'` Light & Dark (tested in Task 4).
